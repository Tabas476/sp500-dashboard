
# S&P 500 Sector Dashboard MVP

## Setup

1. Instala Python 3.11+
2. Instala dependencias:

pip install -r requirements.txt

3. Crea carpeta:
.streamlit/secrets.toml

4. Dentro pega:

FMP_API_KEY = "TU_API_KEY"

5. Ejecuta:

streamlit run app.py

## Deploy gratis
- Streamlit Cloud
- Render
- Railway

## Funciones incluidas
- Índices principales
- ETFs sectoriales GICS
- Ranking de sectores
- Holdings top 5
